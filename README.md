# 卫戍协议攻略 Skill

面向《明日方舟》**卫戍协议·规程·序列Ⅰ**的攻略知识库与 AI 建议 Skill。根据 20 项独立来源整理 11 个套路，保留每个套路的作者、同套路的不同作者变体、操作条件及原链接。

资料整理日期：**2026-11-13**。适合选队、拿牌、升本、装备、站位和已有对局分析。

## 在 Codex 中安装

将下面这句话发给支持 Skill Installer 的 Codex：

```text
请使用 $skill-installer 安装这个 Skill：https://github.com/Nijuu-20/garrison-strategy-guide/tree/main/garrison-strategy-guide
```

安装完成后可以直接提问：

```text
请用 $garrison-strategy-guide 分析这局卫戍协议。我会提供当前截图、策略、禁用、回合、资金和商店；请给出这回合买什么、是否升本、替代方案，并标明攻略作者。
```

若未显示新技能，可新开对话或重启 Codex 后再检查。也可下载 [Skill 压缩包](garrison-strategy-guide.zip)，将其中整个 `garrison-strategy-guide` 文件夹导入支持 `SKILL.md` 的工具，具体位置以该工具为准。Codex 的手动安装位置和调用方式见 [官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)。

公开仓库方便分享和安装；其他用户仍需在自己的工具中安装。此仓库没有注册为全平台插件，也不会自动接入某个游戏助手的 AI 请求。

## 署名与适用范围

攻略来自原作者的公开视频和图文。本库提供整理后的摘要与引用，不收录原视频、图文原图或完整转写。同套路涉及多位作者时保留全部对应作者；直播、切片、文案等角色分别记录，不据上传顺序认定首创。引用或继续整理时请保留作者、来源链接及变体条件。

本批资料由 19 个视频的音轨转写、代表性画面、简介和一篇含 11 张图片的图文核对整理；没有逐帧连续观看、游戏复现或胜率测量。部分来源只展示中后期阵容，不能由此推造完整开局。游戏更新或切换序列后，应重新核对规则；不承诺“必过”。

如需纠错，请在 Issue 中注明套路编号、相关句子、来源链接或时间点，以及适用游戏版本。
