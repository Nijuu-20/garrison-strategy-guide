# 卫戍协议攻略 Skill

适用 **规程·序列Ⅰ**，资料更新至 **2026-11-15**。收录 **36条路线、74个来源**（73个视频与1篇11图图文），其中 **35条策略候选、1条探索**。本轮独立检索新增54个视频、25条路线，并补充原有路线作者变体；另有7组技能、叠层、经济、站位和转职参考。

同套路保留全部已使用作者；各作者变体独立署名，直播、切片、制作与文案角色区分。数量不代表胜率或首创认证。视频按解说转写、图文和关键帧整理，不是连续逐帧观看，未做游戏复现。后期例证不补造开局，失败和未通关素材明确注明。

## 使用

- 人阅读：[攻略总览](攻略总览.html)，可下载后离线搜索作者、阵营、干员和盟约。
- 支持本地 Skill 的助手：将 `garrison-strategy-guide/` 完整目录放入其技能目录，加载 `SKILL.md`。其他用户可以下载公开仓库后使用。
- API/自建助手：依当前版本、禁选、策略与已有牌选路线，再把 `SKILL.md`、相关路线文档和来源信息放进本次AI上下文；按需附加机制/通用补充。公开仓库本身不会自动接入任意助手。
- `卫戍协议_攻略知识库.json` 为结构化数据；`retrieval.json` 为现有卫戍协议助手的筛选条件示例，匹配是应用推断，不是作者强度排名。R25不参与默认检索。
- 本地包：[garrison-strategy-guide.zip](garrison-strategy-guide.zip)。

## 内容边界

按版本整理；其他序列或规则改动必须复核。高阶常规招募与晋升奖励分开，未获得的球/装备/精锐不虚算。保留不同作者的升本、技能和转型分支，不能拼成所有组件必得的理想阵容。新来源逐项记录作者、原链接、核对位置与使用范围，发现候选登记于 `intake-audit.json`。
